# Trade90 SEO audit and implementation — 18 October 2026

## Scope and evidence
Reviewed live homepage text, repository templates, generated HTML, sitemap publishing and IndexNow. Audited 54 index.html pages plus the separate 404 build output. The pre-change sitemap contains 52 URLs. All audited pages have descriptions; the two tool pages share a generic H1. Some bank/calendar titles are long; length is not itself an indexing error. Source data freshness has known problems and is being repaired separately.

No Ahrefs, Semrush or Search Console account metrics were available. Ahrefs connection was offered; no matching Semrush integration was found. Windsor.ai can provide Search Console access but is not connected. Search engine sample results are not a verified index count, rank tracker, backlink audit or keyword-volume dataset. Direct public HTTP inspection from this environment sometimes returns 403; web retrieval can read the homepage. No measured Core Web Vitals are claimed.

## Implemented fixes
- Removed obsolete tools-directory exclusions from Astro sitemap, sitemap validator and IndexNow validator. Require the public tools hub and calculator in generated sitemaps.
- Replaced identical generic tool H1s with descriptive headings and shortened calculator search title.
- Made pair titles and descriptions reflect interest rates, inflation, unemployment and GDP; preserved all existing canonical URLs.
- Added factual publisher/WebPage structured data and guide breadcrumbs. Calculator WebApplication metadata describes its real functionality; no invented reviews, ratings or author credentials.
- Added a practical two-economy fundamental-analysis checklist and contextual links between guides, pairs and risk calculator. Source links and reporting-period distinctions are explicit.
- Linked the editorial policy from all footers and attributed educational content to the actual Trade90 publisher.

High-volume queries need useful original research, reliable updates, legitimate citations and earned links; metadata changes alone do not establish authority.
